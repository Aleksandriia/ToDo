# ToDo List с Напоминаниями (Web версия)

Это веб-приложение для управления задачами с возможностью установки напоминаний. Приложение создано с использованием фреймворка Flask и предоставляет веб-интерфейс для удобного управления вашими делами.

## Особенности

- Добавление, редактирование и удаление задач
- Установка даты выполнения и времени напоминания
- Отметка задач как выполненных
- Автоматическое сохранение данных в JSON-файл
- Удобный веб-интерфейс с таблицей задач
- Адаптивный дизайн для разных устройств

## Требования

- Python 3.x
- Flask

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.x
2. Установите Flask:
```bash
pip install Flask
```
3. Скачайте файл `web_todo_app.py`
4. Запустите приложение:
```bash
python web_todo_app.py
```
5. Откройте в браузере адрес: http://localhost:5000

## Использование

Приложение имеет интуитивно понятный интерфейс:

1. **Добавить задачу** - форма в левой части экрана для создания новой задачи
2. **Изменить задачу** - кнопка "Изменить" рядом с каждой задачей
3. **Удалить задачу** - кнопка "Удалить" рядом с каждой задачей
4. **Выполнить/Отменить** - кнопка для переключения статуса выполнения задачи

## Форматы дат

- Для полей "Выполнить до" и "Напомнить" используйте формат, предусмотренный браузером (обычно YYYY-MM-DD HH:MM)

## Хранение данных

Все данные сохраняются в файле `todo_data.json` в той же директории, что и приложение.
