# ToDo List с Напоминаниями

Это приложение для управления задачами с возможностью установки напоминаний. Представлено в нескольких вариантах для разных способов использования.

## Доступные версии

1. **Консольное приложение** (`todo_app.py`) - классическое консольное приложение с текстовым интерфейсом
2. **Графическое приложение** (`gui_todo_app.py`) - desktop-приложение с графическим интерфейсом на tkinter
3. **Веб-приложение** (`web_todo_app.py`) - веб-приложение с интерфейсом в браузере на Flask

## Особенности

- Добавление, редактирование и удаление задач
- Установка даты выполнения и времени напоминания
- Отметка задач как выполненных
- Автоматическое сохранение данных в JSON-файл
- Удобный интерфейс для управления задачами

## Требования

- Python 3.x

Для веб-приложения дополнительно требуется:
- Flask

## Установка и запуск

### Консольное приложение:
```bash
python todo_app.py
```

### Графическое приложение:
```bash
python gui_todo_app.py
```
*Примечание: для запуска графического интерфейса необходимо, чтобы в системе были установлены библиотеки Tk.*

### Веб-приложение:
```bash
pip install Flask
python web_todo_app.py
```
После запуска откройте в браузере: http://localhost:5000

## Форматы дат

- Для полей даты и времени используйте формат, поддерживаемый конкретной версией приложения
- Обычно используется формат: `дд.мм.гггг чч:мм` или формат, предусмотренный элементом ввода в браузере

## Хранение данных

Все данные сохраняются в файле `todo_data.json` в той же директории, что и приложение.

## Возможные улучшения
