# ToDo List с Напоминаниями (GUI версия)

Это desktop-приложение для управления задачами с возможностью установки напоминаний. Приложение создано с использованием библиотеки tkinter и предоставляет графический интерфейс для удобного управления вашими делами.

## Особенности

- Добавление, редактирование и удаление задач
- Установка даты выполнения и времени напоминания
- Отметка задач как выполненных
- Автоматическое сохранение данных в JSON-файл
- Удобный графический интерфейс с таблицей задач

## Требования

- Python 3.x
- Библиотека tkinter (входит в стандартную библиотеку Python)

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.x
2. Скачайте файл `gui_todo_app.py`
3. Запустите приложение:

```bash
python gui_todo_app.py
```

## Использование

Приложение имеет интуитивно понятный интерфейс:

1. **Добавить задачу** - открывает диалоговое окно для создания новой задачи
2. **Редактировать задачу** - позволяет изменить существующую задачу
3. **Удалить задачу** - удаляет выбранную задачу
4. **Отметить как выполненное** - переключает статус выполнения задачи

При двойном клике на задаче также открывается окно редактирования.

## Форматы дат

- Для полей "Выполнить до" и "Напомнить" используйте формат: `дд.мм.гггг чч:мм` (например, 25.12.2026 14:30)

## Хранение данных

Все данные сохраняются в файле `todo_data.json` в той же директории, что и приложение.
